
# InternMatch – Smart Internship Platform

## Live Website
Visit the deployed application: [InternMatch](https://internmatch-wmt8.onrender.com/)

## Project Overview
InternMatch is a web-based platform designed to help students discover internships and submit applications online. Students can register, log in, browse internship opportunities, apply for internships, save opportunities, and track application statuses.

## 2. Sprint Planning
The project work is divided into sprints. Each sprint focuses on a set of related features.

### Sprint 1 – Project Setup and Authentication
- Set up the frontend and backend.
- Configure the MySQL database.
- Implement student registration and login.
- Test authentication.

### Sprint 2 – Internship Management
- Display internship opportunities.
- Implement internship search and browsing.
- Add save internship functionality.
- Connect the frontend to backend APIs.

### Sprint 3 – Applications and Status Tracking
- Implement the Apply feature.
- Store applications in the database.
- Display student application history.
- Support application status tracking.

### Sprint 4 – Testing and Deployment
- Test frontend and backend integration.
- Verify database connectivity.
- Deploy the application using Render.
- Fix errors and improve usability.

### Future Sprint
- Develop company/recruiter authentication.
- Build a company dashboard to review applications.
- Add skill-based internship matching.
- Add interview invitation and notification features.

## 5. Scrum Master
The Scrum Master facilitates the Scrum process and helps the team work effectively.

### Responsibilities
- Organize sprint planning meetings.
- Help the team understand sprint goals.
- Monitor progress and identify blockers.
- Encourage communication among team members.
- Support sprint reviews and retrospectives.
- Help the team improve its development process.

### Scrum Activities
- **Sprint Planning:** Select tasks for the upcoming sprint.
- **Daily Scrum:** Share progress, planned work, and blockers.
- **Sprint Review:** Demonstrate completed features.
- **Sprint Retrospective:** Discuss what went well and what can improve.

## 6. Project Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Database:** MySQL
- **Authentication:** JSON Web Tokens (JWT) and bcrypt
- **Version Control:** GitHub
- **Deployment:** Render
